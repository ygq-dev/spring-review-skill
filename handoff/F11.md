## 2. 关键决定

1. 包名 `dev.springreview`；用 Spring Boot parent 但不引入 starter。
2. 静态工具不进依赖；M10 命令行调用。
3. DIFF 用 JGit `FileHeader.toEditList` 精算新侧行号。
4. M07 以 rules/index.json 为唯一入口；多文档 YAML + A5 Schema 校验。
5. M08 首发版为简化过滤；六层精确匹配留 F4.1。
6. M12 五个检测器 + LLM 语义分支（默认关闭）。
7. LLM 触发条件：`parameters.use_llm=true`。
8. report_id = RPT-YYYY-NNNN；同日 N+1。
9. latest 原子替换；history/YYYY/MM/DD/<report_id>/。
10. CI 默认 `--offline`。
