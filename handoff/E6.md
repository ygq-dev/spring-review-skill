关键决定：
- 三工具：Checkstyle 10.17.0 默认启用、PMD 7.4.0 默认启用、SpotBugs 4.8.6 默认关闭。
- 调用方式：命令行调用，固定版本；输出 XML 到系统临时目录。
- M10 三接口：runAll、runTool、adapt；均不抛异常，失败通过状态码体现。
- ToolRun 适配对齐 A6：tool、tool_version、status、started_at、ended_at、duration_ms、exit_code、issues_count、error_message。
- 状态判定：SUCCESS、FAILED、SKIPPED、TIMEOUT 四种。
- IssueCandidate 适配：工具原生 ID → SRS-* rule_id 映射；未映射默认丢弃并计数。
- 工具开关：enabled=true 且被 M08 requiredTools 选中才运行。
- strict 模式：工具 FAILED/TIMEOUT/解析失败可退出 5。
- 只读保证：不写 .class/build/target/缓存到目标仓库；临时产物写系统临时目录。
- SpotBugs 无编译产物时 SKIPPED。
