关键决定：
- M18 四接口：logger(name)、metric(name,tags,value)、traceId()、redact(value)；不可关闭；日志默认 stderr；UTF-8 强制。
- 结构化日志默认文本 key=value；必含 ts、level、logger、trace_id、module、event、message；无 TRACE，最细 DEBUG。
- 日志级别：ERRORWARNINFODEBUG；默认 INFO；--log-level 覆盖。
- traceId：每次 M01 run 生成一个；UUID v4 去连字符 32 位 hex；写入 MDC；异步线程池LLM 并发必须复制。
- 脱敏：字段名命中 keysecrettokenpasswordauthorizationapi_keyprivate_keycookiesession 等即脱敏为 [REDACTED]；URL userinfo 与 query 密钥脱敏；主目录替换为 ~；禁止记录 promptresponse 原文、完整源码、完整 diff。
- 指标：内存注册表；低基数标签；INFO 摘要、DEBUG 逐指标；不写目标仓库；JMX 不默认。
- E8 冻结指标保持：llm_requests_total、llm_latency_ms、llm_tokens_total、llm_errors_total、llm_retries_total。
- M19 三接口：map(ReviewResult)、mapException(Exception)、printSummary(ReviewResult)；均不抛异常。
- 退出码 0～6：0 成功未达 failOn；1 达到 failOn；2 CLI配置；3 范围代码收集；4 规则加载；5 报告输出校验；6 内部错误未知异常。
- strict 不改变退出码定义，只把降级、工具 FAILEDTIMEOUT、LLM 降级纳入 failOn 判定；strict 与 --no-validate 冲突返回 2。
- CLI：picocli 4.7.6；stdout 正常摘要；stderr 日志警告错误校验失败路径；GITHUB_ACTIONS=true 时可选 annotations。
- M01 三接口：run(args,env)、parse(args)、printUsage()；run 内生成 traceId、初始化 M18、执行审查、捕获异常、printSummary、返回退出码。
- A6 metrics 映射：total_files_scanned ← files_scanned_total；total_lines_scanned ← lines_scanned_total；duration_ms ← run_duration_ms；tool_success_rate ← tool_success_rate；summary.duration_ms ← run_duration_ms；summary.token_usage ← llm_tokens_total。
- E10 冻结事件名：report.generate、report.validate、report.write、report.archive、report.update_latest。
- 只写 reports 输出目录；日志与指标不写目标仓库。
