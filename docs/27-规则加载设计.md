# 27-规则加载设计

> 范围：E5，仅设计 M07 规则加载器、M08 规则选择器。  
> 冻结引用：A2、A4.2、A5、A6 只读，不修改。E2 M07/M08 契约、E2 数据模型必须遵守。  
> 只读审查：不修改规则文件、不提交、不训练模型。  
> 失败退出码：规则加载/元数据校验失败退出 4。空规则集不致命，但必须警告。

## 1. 设计原则

| 原则         | 决策                                                         |
| ------------ | ------------------------------------------------------------ |
| 冻结优先     | A2、A4.2、A5、A6 为只读事实源；M07/M08 不新增冻结字段，不修改规则 YAML。 |
| 确定性       | 加载顺序、规则顺序、诊断顺序固定；同一输入多次加载结果一致。 |
| 快速失败     | 索引缺失、YAML 解析失败、Schema 校验失败、规则重复、核心索引不一致均退出 4。 |
| 只读与可诊断 | 不写回规则、索引、Schema；所有跳过、失败、降级均产出诊断。   |
| 缓存与重载   | 默认内存缓存；`reload()` 强制失效并重新加载；对外返回不可变 RuleSet。 |

## 2. 规则来源与加载范围

| 来源          | 路径                                              | 用途                                    | 约束                |
| ------------- | ------------------------------------------------- | --------------------------------------- | ------------------- |
| 规则 YAML     | `rules/*.yaml`                                    | 18 个多文档 YAML，每条规则以 `---` 分隔 | 只读；UTF-8；不修改 |
| 规则索引      | `rules/index.json`                                | A4.2 冻结索引，唯一加载入口             | 只读；缺失退出 4    |
| 元数据 Schema | `schema/rule-metadata.schema.json`                | A5，单条规则元数据校验                  | 只读；不修改        |
| 配置路径      | `rules.dir`、`rules.index`、`schema.ruleMetadata` | E3 冻结默认值                           | 不新增必需配置      |

路径与编码：Windows 下使用 E3/E4 约定；路径规范化为绝对路径；UTF-8；索引中的 `file` 与规范化路径比较。

## 3. M07 规则加载器设计

### 3.1 接口

| 接口                                         | 输入                         | 输出                        | 失败                     |
| -------------------------------------------- | ---------------------------- | --------------------------- | ------------------------ |
| `load(rulesDir) -> RuleSet`                  | rulesDir、index.json、Schema | RuleSet、加载诊断、规则版本 | 失败退出 4               |
| `reload() -> RuleSet`                        | 同上，强制绕过缓存           | 新 RuleSet                  | 失败退出 4，不替换旧缓存 |
| `validateMetadata(rule) -> ValidationResult` | 单条规则完整元数据           | ValidationResult            | 不抛异常；返回错误/警告  |

### 3.2 加载流程

| 步骤            | 决策                                                         |
| --------------- | ------------------------------------------------------------ |
| 1. 读索引       | 读 `rules/index.json`；缺失、JSON 解析失败、顶层字段缺失退出 4。 |
| 2. 校验索引     | `count == items.length`；`items[].id` 唯一；`file` 存在。    |
| 3. 读 YAML      | 按 `items[].file` 分组；文件读取按文件名升序，保证确定性。   |
| 4. 多文档解析   | 用 SnakeYAML 安全模式解析多文档 YAML；每条文档独立。         |
| 5. 反序列化     | 每条文档经 Jackson 绑定为完整 A2 元数据对象，再投影为 E2 Rule。 |
| 6. 元数据校验   | 用 networknt json-schema-validator 1.4.0 按 A5 校验单条规则。 |
| 7. 索引一致性   | 校验 `items[]` 与 YAML 的 id、分类、文件、状态、严重级、版本等。 |
| 8. 状态过滤     | 默认仅保留 `status=ACTIVE`；其余记录到 `skippedByStatus`。   |
| 9. 组装 RuleSet | `rules` 按 `index.items` 顺序；`indexVersion` 来自 `index.version`；`loadedAt` UTC ISO-8601。 |

### 3.3 多文档 YAML 解析

| 项               | 决策                                                       |
| ---------------- | ---------------------------------------------------------- |
| 解析器           | SnakeYAML 安全构造，禁止任意类型实例化。                   |
| 文档边界         | `---` 分隔；空文档忽略；文档序号从 1 开始。                |
| 单条规则反序列化 | SnakeYAML 得到 Map/List 后，Jackson 绑定为完整元数据对象。 |
| 错误定位         | 记录文件、文档序号、行列、rule_id（若可解析）。            |
| 部分成功         | 不允许部分成功进入 RuleSet；有 ERROR 即退出 4。            |

### 3.4 与 rules/index.json 的关系

| 关系     | 决策                                                    |
| -------- | ------------------------------------------------------- |
| 唯一入口 | 不扫描未在 index 中出现的 YAML 规则。                   |
| 顺序     | `RuleSet.rules` 顺序以 `index.items` 为准。             |
| 全量校验 | 索引一致性针对全部 items，不因默认 ACTIVE 过滤而减少。  |
| 状态过滤 | 先全量校验，再按 `status=ACTIVE` 过滤生成对外 `rules`。 |
| 退出码   | 核心不一致退出 4。                                      |

### 3.5 与 schema/rule-metadata.schema.json 的关系

| 项            | 决策                                                         |
| ------------- | ------------------------------------------------------------ |
| 校验对象      | 单条规则完整 A2 元数据，不是 E2 投影后的 Rule。              |
| 校验器        | networknt json-schema-validator 1.4.0。                      |
| Schema 事实源 | 必填、可空、枚举、格式以 A5 为准；加载器不重定义。           |
| 额外校验      | `rule_id` 格式、18 类一级分类、枚举白名单、`schema_version` 兼容、索引 id 一致。 |
| 失败          | 收集全部 ValidationResult；任一 ERROR 退出 4。               |

### 3.6 状态过滤

| 状态                               | 默认行为                       |
| ---------------------------------- | ------------------------------ |
| ACTIVE                             | 加载进 RuleSet.rules。         |
| DRAFT、REVIEW、DEPRECATED、REMOVED | 不加载；记录 skippedByStatus。 |
| 索引与 YAML 状态不一致             | 核心字段不一致，退出 4。       |
| 过滤后空                           | 非致命；WARN；返回空 RuleSet。 |

### 3.7 加载顺序与确定性

| 项       | 决策                                          |
| -------- | --------------------------------------------- |
| 文件读取 | 按 `items[].file` 去重后，文件名升序读取。    |
| 规则输出 | 按 `index.items` 顺序输出。                   |
| 诊断输出 | 按文件、文档序号、rule_id、错误码排序。       |
| 缓存键   | 包含路径、mtime、size、配置指纹、加载器版本。 |

## 4. M08 规则选择器设计

### 4.1 接口

| 接口                                                       | 输入                | 输出                    | 失败                 |
| ---------------------------------------------------------- | ------------------- | ----------------------- | -------------------- |
| `select(RuleSet, ReviewScope, AppConfig) -> SelectedRules` | RuleSet、范围、配置 | SelectedRules、跳过原因 | 不可关闭；空集警告   |
| `explain(ruleId) -> SelectionReason`                       | ruleId              | 选择/跳过原因           | 不存在返回 NOT_FOUND |

### 4.2 按 scope.mode 选择

| mode   | 决策                                                         |
| ------ | ------------------------------------------------------------ |
| DIFF   | 使用 E4 变更文件集合与变更模块；规则需匹配变更文件路径、文件类型或模块类型；`exclude` 优先排除。 |
| MODULE | 使用模块列表；按 `module_type`、`build_tool`、`framework`、Java/Spring 版本选择；不要求单文件路径。 |
| FILES  | 使用显式文件列表；按文件类型、路径模式、模块类型选择；忽略变更状态。 |
| 通用   | 无路径模式规则按文件类型/模块类型纳入候选；`exclude` 命中即跳过。 |

### 4.3 按 applies_to 选择

| 维度                | 决策                                                         |
| ------------------- | ------------------------------------------------------------ |
| java_version        | 缺失=全适用；具体值=相等；范围按 A2/E4 约定；无法解析则 WARN 并跳过该规则。 |
| spring_boot_version | 同上。                                                       |
| build_tool          | Maven/Gradle；缺失=全适用；不匹配跳过。                      |
| module_type         | 缺失=全适用；不匹配跳过。                                    |
| framework           | 缺失=全适用；不匹配跳过。                                    |
| exclude             | 路径、模块、文件类型排除；优先级最高。                       |

### 4.4 按文件类型选择

| 项           | 决策                                                         |
| ------------ | ------------------------------------------------------------ |
| 文件类型来源 | E4 ReviewScope 提供扩展名、语言、路径角色（main/test/build/config）。 |
| 优先规则     | `Rule.patterns` 中文件类型/路径模式。                        |
| 缺省映射     | 无 patterns 时按 category 默认映射，如 TEST 匹配 `src/test`，BUILD 匹配 `pom.xml`/`build.gradle`。 |
| 不匹配       | 跳过并记录原因。                                             |

### 4.5 按 tool 与 detection_method 选择

| 项               | 决策                                                         |
| ---------------- | ------------------------------------------------------------ |
| tool             | 规则 `tool` 为空或 CUSTOM 始终可选；CHECKSTYLE/PMD/ARCHUNIT/SPOTBUGS 需 AppConfig 启用对应工具；HYBRID 任一子工具可用即可。 |
| detection_method | 默认全启用；AppConfig 显式禁用则跳过；MANUAL 默认不自动选，除非显式启用。 |
| 缺失值           | 不阻断；按全适用处理。                                       |

### 4.6 按 enabled 选择

| 项            | 决策                                 |
| ------------- | ------------------------------------ |
| enabled=false | 跳过。                               |
| 非 ACTIVE     | M07 已过滤；若仍出现，M08 再次跳过。 |
| 重复 id       | M07 已保证唯一；M08 不处理重复。     |

### 4.7 无匹配规则处理

| 项      | 决策                                           |
| ------- | ---------------------------------------------- |
| 结果    | `SelectedRules.rules` 为空。                   |
| 诊断    | WARN；`skipped` 记录每规则主要原因或汇总原因。 |
| 退出码  | 不因空集退出 4；由 M03/M12 结合 failOn 决定。  |
| explain | 可查询任意规则最终选择原因。                   |

### 4.8 explain(ruleId)

| 字段          | 内容                                                         |
| ------------- | ------------------------------------------------------------ |
| selected      | true/false                                                   |
| reasonCode    | EXCLUDED、DISABLED、STATUS、SCOPE_MODE、APPLIES_TO、FILE_TYPE、TOOL、DETECTION、NO_MATCH |
| matched       | 命中的维度与证据                                             |
| unmatched     | 未命中的条件                                                 |
| scopeEvidence | 文件、模块、版本、工具、配置来源                             |
| priority      | exclude > enabled/status > scope.mode > applies_to > 文件类型 > tool/detection |

## 5. Rule 结构（对齐 E2）

| 字段             | 类型          | 来源                              | 说明                              |
| ---------------- | ------------- | --------------------------------- | --------------------------------- |
| id               | string        | `rule_id`                         | 稳定唯一                          |
| title            | string        | `name`                            | 展示标题                          |
| severity         | enum          | `severity`                        | BLOCKER/CRITICAL/MAJOR/MINOR/INFO |
| category         | string        | `category_l1`                     | 一级分类；二级在只读元数据视图    |
| detection_method | enum          | `detection_method`                | A2 枚举                           |
| tool             | enum          | `tool`                            | A2 枚举                           |
| enabled          | boolean       | `enabled`                         | 是否启用                          |
| patterns         | object/list   | YAML patterns 或只读投影          | 路径/文件类型/检测模式            |
| prompt           | string/object | YAML prompt                       | 规则提示                          |
| examples         | object        | positive_example/negative_example | 正反例                            |
| schemaVersion    | string        | `schema_version`                  | A5 版本                           |

只读元数据视图：M07 内部保留完整 A2 元数据，供 M08 读取 `status`、`applies_to`、`confidence`、`rule_version`、`metadata_version`、`category_l2`、`tags`、`tool_rule_id`、`parameters` 等；不改变 E2 Rule 契约字段。

## 6. RuleSet 结构（对齐 E2）

| 字段         | 类型   | 来源                 | 说明                |
| ------------ | ------ | -------------------- | ------------------- |
| rules        | Rule[] | 过滤后的 ACTIVE 规则 | 按 index.items 顺序 |
| indexVersion | string | `index.version`      | 索引版本            |
| loadedAt     | string | 加载时间             | UTC ISO-8601        |
| sourceDir    | string | `rules.dir`          | 规范化绝对路径      |

只读附加：`diagnostics`、`metadataByRuleId`、`versionInfo`、`skippedByStatus`、`cacheKey`。不改变 E2 稳定字段。

## 7. SelectedRules 结构（对齐 E2）

| 字段            | 类型     | 说明                                  |
| --------------- | -------- | ------------------------------------- |
| rules           | Rule[]   | 选择后的规则，顺序继承 RuleSet        |
| selectionReason | object   | 每个 ruleId 的 SelectionReason 或汇总 |
| skipped         | object[] | 跳过规则与原因                        |

## 8. 索引一致性校验

| 场景                                                         | 行为                                                         | 级别/退出码   |
| ------------------------------------------------------------ | ------------------------------------------------------------ | ------------- |
| `index.json` 缺失                                            | 不自动扫描 YAML                                              | ERROR，退出 4 |
| `count != items.length`                                      | 索引损坏                                                     | ERROR，退出 4 |
| `items[].id` 重复                                            | 索引损坏                                                     | ERROR，退出 4 |
| `items[].file` 不存在                                        | 索引指向缺失文件                                             | ERROR，退出 4 |
| index 有 item，YAML 无对应 `rule_id`                         | 缺失规则                                                     | ERROR，退出 4 |
| YAML 有规则，index 无 item                                   | 多余规则                                                     | ERROR，退出 4 |
| `id/category/subcategory/file/status/severity/version` 不一致 | 核心字段冲突                                                 | ERROR，退出 4 |
| `title/tags` 可选字段不一致                                  | 记录警告，采用 YAML                                          | WARN          |
| `confidence/detection_method/tool` 可选字段不一致            | 双方都缺：跳过；index 缺 YAML 有：WARN 采用 YAML；index 有 YAML 缺：WARN 采用 index；双方都有但不等：ERROR，退出 4 | 见左          |

对应关系：`items[].id == YAML rule_id`；`category == category_l1`；`subcategory == category_l2`；`file` 指向来源文件；`status/severity/version` 必须一致。

## 9. 元数据校验

| 项         | 决策                                                         |
| ---------- | ------------------------------------------------------------ |
| 校验对象   | 单条规则完整 A2 元数据                                       |
| Schema     | `schema/rule-metadata.schema.json`，只读                     |
| 校验器     | networknt json-schema-validator 1.4.0                        |
| 必填/可空  | 以 A5 为准；加载器不重定义                                   |
| 额外强校验 | `rule_id` 格式、18 类一级分类、枚举白名单、`schema_version` 兼容、索引 id 一致 |
| 失败收集   | 收集全部错误后统一判定                                       |
| 失败行为   | 任一 ERROR 退出 4；`validateMetadata` 返回 ValidationResult，不抛异常 |
| 警告       | 不阻断；进入诊断与报告                                       |

## 10. 规则版本与一致性

| 版本字段           | 决策                                                         |
| ------------------ | ------------------------------------------------------------ |
| `rule_version`     | 与 `index.items[].version` 必须一致；不一致退出 4。          |
| `metadata_version` | 主版本必须等于加载器支持主版本，不等 ERROR 退出 4；次版本差异 WARN；补丁版本差异 INFO。 |
| `schema_version`   | 必须与 A5 当前支持版本一致；不匹配退出 4。                   |
| `index.version`    | 写入 `RuleSet.indexVersion`；不要求等于单条 `rule_version`。 |
| 同 id 多版本       | 视为重复规则，退出 4。                                       |
| 版本诊断           | 加载诊断中记录规则版本、Schema 版本、加载器支持范围。        |

## 11. 异常与降级

| 异常                  | 行为                                     | 退出码/级别   |
| --------------------- | ---------------------------------------- | ------------- |
| YAML 解析失败         | 记录文件、文档序号、行列；不部分加载     | ERROR，退出 4 |
| 索引缺失              | 不降级扫描；直接失败                     | ERROR，退出 4 |
| Schema 校验失败       | 收集全部失败；不进入 M08                 | ERROR，退出 4 |
| 规则重复              | 同 rule_id 重复                          | ERROR，退出 4 |
| 空规则集              | 返回空 RuleSet；M08 返回空 SelectedRules | WARN；退出 0  |
| ACTIVE 为空但全量非空 | 记录 skippedByStatus                     | WARN；退出 0  |
| 单文件缺失            | 索引指向文件不存在                       | ERROR，退出 4 |
| 不可关闭/降级         | M07、M08 均不可关闭；无网络、无写操作    | 失败退出 4    |

## 12. 性能与缓存

| 项       | 决策                                                         |
| -------- | ------------------------------------------------------------ |
| 内存缓存 | 默认启用；缓存不可变 RuleSet 与诊断。                        |
| 缓存键   | `rules.dir`、`rules.index`、`schema.ruleMetadata`、mtime、size、配置指纹、加载器版本。 |
| reload   | 强制绕过缓存；成功返回新 RuleSet；失败退出 4，不替换旧缓存。 |
| 线程安全 | 加载完成后不可变发布；并发读取安全。                         |
| 目标     | 冷加载 18 YAML/55 规则 < 500ms；缓存命中 < 50ms；全量校验 < 1s。 |
| 磁盘缓存 | 不使用；只读审查，不落盘。                                   |
| 大规则集 | 按 index 分组流式处理单文件，不长期保留原始 YAML 文本。      |

## 13. 模块接口（对齐 E2 M07/M08 契约）

| 模块 | 职责                                        | 输入                            | 输出                    | 接口                                                         | 依赖                         | 失败/降级                  |
| ---- | ------------------------------------------- | ------------------------------- | ----------------------- | ------------------------------------------------------------ | ---------------------------- | -------------------------- |
| M07  | 加载 rules/*.yaml 与 index.json，校验元数据 | rulesDir、index.json、A5 Schema | RuleSet、诊断、规则版本 | `load(rulesDir) -> RuleSet`；`reload() -> RuleSet`；`validateMetadata(rule) -> ValidationResult` | Jackson YAML、SnakeYAML、M18 | 不可关闭；失败退出 4       |
| M08  | 按范围、文件类型、工具、检测方式过滤        | RuleSet、ReviewScope、AppConfig | SelectedRules、跳过原因 | `select(RuleSet, ReviewScope, AppConfig) -> SelectedRules`；`explain(ruleId) -> SelectionReason` | M07、M18                     | 不可关闭；无匹配空集并警告 |

依赖方向：M07 被 M08 依赖；M08 被 M03、M12 依赖。

## 14. 测试策略

| 类型     | 覆盖                                                         |
| -------- | ------------------------------------------------------------ |
| 单元     | 多文档解析、反序列化、状态过滤、索引一致、Schema 校验、版本兼容、重复、空集。 |
| 集成     | 18 YAML + index 全量加载 55 条；默认 ACTIVE 子集；DIFF/MODULE/FILES；applies_to 各维度；tool/detection；enabled；explain。 |
| 异常夹具 | 坏 YAML、索引缺失、count 错误、id 重复、文件缺失、Schema 失败、版本不匹配、核心字段不一致。 |
| 退出码   | 规则加载失败退出 4；空集警告不退出 4。                       |
| 确定性   | 多次加载顺序一致；缓存命中与 reload 结果一致。               |
| 只读     | 测试前后规则文件、索引、Schema 哈希不变。                    |
| 性能     | 冷加载、缓存命中、reload 耗时断言。                          |
