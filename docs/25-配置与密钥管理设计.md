# 25-配置与密钥管理设计

> 模块：M02 配置与密钥管理  
> 阶段：E3 技术选型 + 模块设计  
> 状态：设计稿，可直接保存为 `docs/25-配置与密钥管理设计.md`  
> 约束：只读审查；不修改代码、不提交、不训练模型；密钥只走环境变量 / CI Secrets / `.env.local`；不引入 Vault、OS Keychain、配置中心。

## 1. 设计原则

1. **单一事实来源**：所有运行配置合并为 `AppConfig`，密钥只以 `SecretRef` 引用，不进入 `AppConfig` 明文。
2. **优先级无歧义**：CLI > 环境变量 > `.env.local` > 配置文件 > 默认值；CI Secrets 通过环境变量注入，归入环境变量层。
3. **只读与无副作用**：M02 只加载、合并、校验、脱敏；不写代码、不修改环境变量、不提交、不训练。
4. **失败可诊断、密钥不泄露**：配置失败退出码 2；日志、报告、归档、异常栈、诊断中不得出现密钥明文。
5. **UTF-8 强制**：Windows 11 GBK 环境下，配置、密钥文件、日志、报告统一 UTF-8。

## 2. 配置源与优先级

### 2.1 配置源

| 配置源                                       | 说明                                                  |
| -------------------------------------------- | ----------------------------------------------------- |
| CLI 参数                                     | 最高优先级；由 `ReviewRequest` 携带                   |
| 环境变量                                     | 含 CI Secrets 注入值；`GITHUB_ACTIONS` 仅标识 CI 环境 |
| `.env.local`                                 | 本地开发密钥与覆盖项；不得提交                        |
| `spring-review.yaml` / `.spring-review.yaml` | 项目配置文件                                          |
| 默认值                                       | 内置默认，最低优先级                                  |

### 2.2 优先级顺序

```text
CLI 参数
  > 环境变量（含 CI Secrets）
  > .env.local
  > spring-review.yaml / .spring-review.yaml
  > 默认值
```

### 2.3 覆盖规则

| 类型       | 规则                                                         |
| ---------- | ------------------------------------------------------------ |
| 标量       | 高优先级非空值覆盖低优先级；未提供不覆盖                     |
| 布尔 CLI   | `--offline`、`--strict`、`--no-llm`、`--no-markdown`、`--no-validate` 出现即生效 |
| 启用型 CLI | `--enable-checkstyle`、`--enable-pmd`、`--enable-spotbugs` 出现即置 `true` |
| 列表       | CLI 出现 `--module`、`--files`、`--format` 时整体替换低优先级列表 |
| 路径       | 相对路径以 `review.repoRoot` 为基准解析                      |
| 空值       | 环境变量空字符串视为未设置；YAML `null` 视为未设置           |
| CI Secrets | 作为环境变量值参与合并，不单独提高优先级                     |

## 3. AppConfig 结构

`AppConfig` 只承载 E2 冻结清单中的配置项；密钥不进入 `AppConfig`。  
`configPath`、`offline`、`validate` 为加载/运行控制项，来自 E2 CLI/环境变量清单，随 `AppConfig` 返回或由 `ReviewRequest` 传递。

## 4. SecretRef 结构

### 4.1 密钥标识方式

| 字段              | 类型         | 说明                                       |
| ----------------- | ------------ | ------------------------------------------ |
| `name`            | String       | 逻辑名，如 `llm.apiKey`                    |
| `provider`        | String       | `deepseek` / `openai` / 自定义             |
| `source`          | Enum         | `ENV`、`CI_SECRET`、`DOTENV_LOCAL`、`NONE` |
| `envVarName`      | String       | 实际环境变量名，可诊断                     |
| `present`         | Boolean      | 是否存在                                   |
| `redactedValue`   | String       | 固定 `***`，不存明文                       |
| `resolutionOrder` | List<String> | 解析顺序                                   |

### 4.2 密钥来源解析

| 条件                    | 解析顺序                                               |
| ----------------------- | ------------------------------------------------------ |
| `llm.provider=deepseek` | `DEEPSEEK_API_KEY` > `LLM_API_KEY` > `.env.local` 同键 |
| `llm.provider=openai`   | `OPENAI_API_KEY` > `LLM_API_KEY` > `.env.local` 同键   |
| 自定义 provider         | `LLM_API_KEY` > `.env.local` 同键                      |
| CI 环境                 | 环境变量由 CI Secrets 注入，`source=CI_SECRET`         |
| 本地                    | `.env.local` 注入，`source=DOTENV_LOCAL`               |

`SecretRef` 不保存明文；需要使用时按 `name` 临时解析，使用后清理。

### 4.3 密钥生命周期

| 阶段 | 行为                                                         |
| ---- | ------------------------------------------------------------ |
| 加载 | 从环境变量 / CI Secrets / `.env.local` 解析，生成 `SecretRef` |
| 合并 | 只合并 `present`、`source`、`envVarName`，不合并明文         |
| 使用 | 通过 `resolveSecret(name)` 临时获取，供 LLM 客户端调用       |
| 清理 | 使用后立即清理临时字符缓冲；不缓存明文到 `AppConfig`         |
| 诊断 | 只输出 `name`、`source`、`present`、`redactedValue`          |
| 禁止 | 不写入报告、日志、归档、异常栈、测试快照                     |

## 5. 配置文件格式（spring-review.yaml）

### 5.1 完整示例

```yaml
review:
  mode: diff
  repoRoot: .
  baseRef: HEAD~1
  headRef: HEAD
  modulePaths: []
  filePaths: []

rules:
  dir: rules
  index: rules/index.json

schema:
  reviewReport: schema/review-report.schema.json
  ruleMetadata: schema/rule-metadata.schema.json

output:
  dir: reports
  latestDir: reports/latest
  historyPattern: reports/history/YYYY/MM/DD/<report_id>/
  formats:
    - markdown
    - json

llm:
  enabled: true
  provider: deepseek
  baseUrl: https://api.deepseek.com
  model: deepseek-chat
  timeoutMs: 60000
  maxConcurrency: 4
  temperature: 0.1
  maxTokens: 4096

static:
  checkstyle:
    enabled: true
  pmd:
    enabled: true
  spotbugs:
    enabled: false

exit:
  failOn: CRITICAL
  strict: false

logging:
  level: INFO
```

### 5.2 字段说明

| 字段                                   | 必填 | 说明                                     |
| -------------------------------------- | ---- | ---------------------------------------- |
| `review.mode`                          | 否   | 审查模式，默认 `diff`                    |
| `review.repoRoot`                      | 否   | 仓库根目录，默认当前目录                 |
| `review.baseRef` / `headRef`           | 否   | diff 范围                                |
| `review.modulePaths` / `filePaths`     | 否   | 指定模块 / 文件                          |
| `rules.dir` / `index`                  | 否   | 规则目录与索引                           |
| `schema.reviewReport` / `ruleMetadata` | 否   | Schema 路径                              |
| `output.*`                             | 否   | 输出目录、历史模式、格式                 |
| `llm.*`                                | 否   | LLM 开关、供应商、模型、并发、超时、采样 |
| `static.*`                             | 否   | 静态检查开关                             |
| `exit.failOn` / `strict`               | 否   | 退出阈值与严格模式                       |
| `logging.level`                        | 否   | 日志级别                                 |

## 6. .env.local 格式与加载

### 6.1 格式

```dotenv
# UTF-8, 无 BOM
LLM_API_KEY=***
DEEPSEEK_API_KEY=***
OPENAI_API_KEY=***
SPRING_REVIEW_LLM_PROVIDER=deepseek
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
MODE=diff
OFFLINE=false
LOG_LEVEL=INFO
SPRING_REVIEW_OUTPUT_DIR=reports
RULES_DIR=rules
SPRING_REVIEW_CONFIG=spring-review.yaml
```

### 6.2 加载规则

| 项     | 规则                                                |
| ------ | --------------------------------------------------- |
| 位置   | `review.repoRoot/.env.local`                        |
| 编码   | UTF-8，兼容 BOM                                     |
| 语法   | `KEY=VALUE`；忽略空行与 `#` 注释；不执行 shell 展开 |
| 覆盖   | 不覆盖已存在的环境变量                              |
| 优先级 | 低于环境变量，高于配置文件                          |
| 安全   | 不提交、不归档、不输出原文                          |
| 支持键 | E2 环境变量清单中的键，密钥键仅进入 `SecretRef`     |

## 7. 密钥脱敏规则

### 7.1 必须脱敏字段

| 字段 / 键                               | 处理                 |
| --------------------------------------- | -------------------- |
| `LLM_API_KEY`                           | 脱敏为 `***`         |
| `DEEPSEEK_API_KEY`                      | 脱敏为 `***`         |
| `OPENAI_API_KEY`                        | 脱敏为 `***`         |
| 任何 `*_API_KEY`、`*_TOKEN`、`*_SECRET` | 脱敏为 `***`         |
| `Authorization`、`Cookie`、私钥         | 脱敏为 `***`         |
| `llm.baseUrl` 含 userinfo               | 去除 userinfo 后输出 |

### 7.2 脱敏后表现

| 位置          | 表现                                                   |
| ------------- | ------------------------------------------------------ |
| 日志          | `LLM_API_KEY=***`                                      |
| 诊断          | `SecretRef{name=llm.apiKey, source=ENV, present=true}` |
| 报告 Markdown | 不出现密钥字段                                         |
| 报告 JSON     | 不出现密钥字段                                         |
| 异常栈        | 不出现密钥值                                           |
| 配置视图      | `AppConfigView` 中密钥字段为 `***` 或省略              |

### 7.3 禁止写入位置

密钥禁止写入：报告、日志、归档、异常栈、诊断原始输出、测试快照、CI 构件、Markdown/JSON 产物。  
禁止打印全量环境变量。

## 8. 配置校验

| 校验类型 | 规则                                                         | 失败行为      |
| -------- | ------------------------------------------------------------ | ------------- |
| 必填项   | `mode=diff` 时 `baseRef/headRef` 必填；`repoRoot` 必须存在；`rules.dir/index`、`schema.*` 必须存在；`output.dir` 可写 | 退出 2        |
| 类型     | 布尔、整数、长整数、浮点、列表、路径、枚举                   | 退出 2        |
| 范围     | `timeoutMs` 1..600000；`maxConcurrency` 1..32；`temperature` 0.0..2.0；`maxTokens` 1..128000；`logging.level` 合法枚举 | 退出 2        |
| 互斥     | `offline=true` 时强制 `llm.enabled=false`；`--no-llm` 与 LLM 连接参数同时出现时警告并禁用 LLM；`--no-markdown` 与 `output.formats` 仅 markdown 时结果为 json | 退出 2 或降级 |
| 密钥     | 密钥缺失不直接判配置失败；按 `strict` 与 `offline` 降级      | 见第 12 节    |
| 配置文件 | `--config` 指定但不存在 -> 退出 2；默认配置文件不存在 -> 忽略 | 退出 2        |

校验失败输出脱敏诊断到 stderr，退出码 2，不生成报告。

## 9. 配置诊断

### 9.1 成功诊断

- 配置源列表与生效顺序
- 每个字段最终来源
- 覆盖链：默认 -> YAML -> `.env.local` -> 环境变量 -> CLI
- `SecretRef` 列表：`name`、`source`、`present`、`redactedValue`
- 降级信息：如 LLM 因缺密钥降级 offline
- 脱敏后的 `AppConfigView`

### 9.2 失败诊断

- 退出码 2
- 失败字段、失败类型、期望值、实际值
- 建议修复方式
- 不包含密钥明文

### 9.3 AppConfigView

与 `AppConfig` 同结构；密钥字段不出现在 `AppConfig`，诊断中只出现 `SecretRef` 脱敏视图。

## 10. Windows 编码处理

| 项           | 约定                                                         |
| ------------ | ------------------------------------------------------------ |
| JVM          | 强制 `-Dfile.encoding=UTF-8`                                 |
| 配置文件     | UTF-8 无 BOM；读取兼容 BOM                                   |
| `.env.local` | UTF-8 无 BOM                                                 |
| 控制台       | 建议 `chcp 65001`；输出统一 UTF-8                            |
| 日志/报告    | 统一 UTF-8                                                   |
| GBK 注意     | 不使用系统默认编码读写；不使用 `FileReader` 默认编码；路径含中文时以 UTF-8 处理 |
| Git 输出     | 以 UTF-8 解析，避免 GBK 乱码                                 |

## 11. 模块接口

| 接口                                 | 输入                                           | 输出            | 说明                                             |
| ------------------------------------ | ---------------------------------------------- | --------------- | ------------------------------------------------ |
| `load(ReviewRequest) -> AppConfig`   | CLI 参数、环境变量快照、工作目录、默认配置路径 | `AppConfig`     | 加载、合并、校验、生成 `SecretRef`；只读无副作用 |
| `resolveSecret(name) -> SecretRef`   | 逻辑密钥名                                     | `SecretRef`     | 按 provider 与来源解析；不返回明文               |
| `redact(AppConfig) -> AppConfigView` | `AppConfig`                                    | `AppConfigView` | 生成脱敏配置视图，供日志/诊断/报告               |

## 12. 异常与降级

| 场景                                            | 行为                                             | 退出码 |
| ----------------------------------------------- | ------------------------------------------------ | ------ |
| CLI/配置解析失败                                | 输出脱敏诊断                                     | 2      |
| 配置校验失败                                    | 输出脱敏诊断                                     | 2      |
| LLM 密钥缺失，`strict=false` 且 `offline=false` | 降级 `offline=true` 或 `llm.enabled=false`，WARN | 继续   |
| LLM 密钥缺失，`strict=true` 且 `offline=false`  | 退出                                             | 2      |
| `offline=true`                                  | 跳过 LLM，不要求密钥                             | 继续   |
| 规则加载失败                                    | 由 M03/M02 边界报告                              | 4      |
| 报告/输出/校验失败                              | 由 M14 报告                                      | 5      |
| 内部错误                                        | 脱敏异常                                         | 6      |

## 13. 测试策略

### 13.1 单元测试要点

- 优先级：CLI > 环境变量 > `.env.local` > YAML > 默认值
- 覆盖：标量、布尔、列表、路径、空值
- 默认值：全部字段默认值
- 类型/范围/互斥校验
- 脱敏：日志、诊断、异常栈无密钥
- `SecretRef`：来源解析、provider 顺序、`present` 状态
- `.env.local`：不覆盖环境变量、UTF-8、BOM、注释、引号
- Windows：GBK 环境、UTF-8 强制、中文路径

### 13.2 集成测试要点

- CLI + 环境变量 + `.env.local` + YAML 组合
- CI Secrets 模拟：`GITHUB_ACTIONS=true` + 环境变量注入
- 缺密钥降级：`strict=false` 降级，`strict=true` 退出 2
- 诊断输出：脱敏配置视图
- 报告/日志/归档/异常栈无密钥
- 测试夹具使用假密钥，不包含真实密钥

## 14. 未决问题

2. `--no-validate` 是否只影响报告校验，还是也影响规则/Schema 校验。
3. `.env.local` 是否只搜索 `repoRoot`，还是支持向上查找。
4. CI Secrets 识别是否仅依赖 `GITHUB_ACTIONS`，还是支持通用 CI 环境变量。
5. 脱敏是否允许显示最后 4 位；当前设计固定 `***`。
6. Java 环境下密钥临时缓冲清理的可行边界。
7. 日志与配置视图的边界。
