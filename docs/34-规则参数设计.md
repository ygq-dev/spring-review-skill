## 2. 参数详情

### SRS-SEC-01-001 硬编码密钥

```yaml
parameters:
  patterns:
    - '(?i)\b(password|passwd|pwd|secret|api[_-]?key|apikey|token|access[_-]?key)\b\s*=\s*"[^"]{3,}"'
```
