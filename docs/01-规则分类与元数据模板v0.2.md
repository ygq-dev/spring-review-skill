定义 Spring Review Skill 的规则分类、编号规则、元数据模板、生命周期与版本标注规范，供规则元数据 Schema、索引文件与审查报告引用。

## 3. 规则分类与元数据模板

### 3.1 分类原则

- 规则按一级分类、二级分类组织。
- 分类码用于规则 ID 与测试用例 ID 的组成。
- v0.2 不修改既有分类码、字段名、枚举与编号规则。

### 3.2 一级分类

一级分类码沿用 v0.1，不在 v0.2 变更。

### 3.3 二级分类

二级分类码沿用 v0.1，不在 v0.2 变更。

### 3.4 编号规则

规则 ID 编号规则沿用 v0.1，不在 v0.2 变更。

测试用例 ID 格式为：

```text
TC-<一级分类码>-<三位序号>
```

### 3.5 元数据模板

元数据模板字段以 docs/04-规则元数据Schema.md（A5 冻结版）与 schema/rule-metadata.schema.json 为准。

v0.2 合并并明确以下字段：

| 字段             | 类型                | 说明                                                         |
| ---------------- | ------------------- | ------------------------------------------------------------ |
| status           | string              | 生命周期状态；枚举沿用 A5 冻结版，不新增枚举                 |
| deprecated_at    | string，format date | 可选；status=DEPRECATED 或 REMOVED 时必填                    |
| removed_at       | string，format date | 可选；status=REMOVED 时必填                                  |
| test_cases       | array&lt;string&gt; | 测试用例 ID 数组，ID 格式 TC-&lt;一级分类码&gt;-&lt;三位序号&gt;，需存在于 tests/cases/index.json |
| rule_version     | string              | 每条规则自己的版本，语义化版本                               |
| metadata_version | string              | 元数据模板版本，语义化版本                                   |
| schema_version   | string              | JSON Schema 版本，语义化版本                                 |

### 3.6 生命周期与测试

#### test_cases

- 类型：array&lt;string&gt;。
- 说明：测试用例 ID 数组，ID 格式 `TC-<一级分类码>-<三位序号>`，需存在于 `tests/cases/index.json`。
- 约束：每个元素必须匹配 `TC-<一级分类码>-<三位序号>`，且必须存在于 `tests/cases/index.json`。

#### deprecated_at

- 类型：string。
- format：date。
- 可选性：可选。
- 必填条件：`status = DEPRECATED` 或 `status = REMOVED` 时必填。
- 说明：规则废弃日期。

#### removed_at

- 类型：string。
- format：date。
- 可选性：可选。
- 必填条件：`status = REMOVED` 时必填。
- 说明：规则移除日期。

#### 条件约束

- `status = DEPRECATED` 时，`deprecated_at` 必填。
- `status = REMOVED` 时，`deprecated_at`、`removed_at` 必填。
- `deprecated_at` 出现时，`status` 必须为 `DEPRECATED` 或 `REMOVED`。
- `removed_at` 出现时，`status` 必须为 `REMOVED`。

## 10. 版本标注规范

### 10.1 版本字段

- `rule_version`：每条规则自己的版本，语义化版本。
- `metadata_version`：元数据模板版本，语义化版本。
- `schema_version`：JSON Schema 版本，语义化版本。

### 10.2 版本关系

- `rule_version`、`metadata_version`、`schema_version` 三者独立演进，各自语义化版本。
- `metadata_version` 与 `schema_version` 独立演进，各自语义化版本；不要求同步递增，不互相派生。
- 本文档版本独立标注，当前为 v0.2。
