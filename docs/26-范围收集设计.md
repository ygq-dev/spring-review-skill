# docs/26-范围收集设计.md

> 范围：M04 范围解析、M05 Git Diff 收集、M06 模块/文件收集。  
> 状态：E4 设计，供 F 阶段实现。只读审查，不修改目标仓库。

## 1. 设计原则

1. **只读优先**：仅读取 Git 对象、工作区文件、构建描述文件；不写目标仓库、不执行构建、不 checkout/reset。
2. **契约冻结**：严格对齐 E2 的 M04/M05/M06 接口、数据模型、依赖方向、退出码。
3. **模式互斥**：一次 ReviewRequest 只解析为 DIFF、MODULE、FILES 之一。
4. **路径与编码确定性**：内部统一 `/` 路径、UTF-8 读取、1-based 闭区间行号；Windows 路径必须规范化。
5. **范围错误硬失败，非当前模式可降级**：当前模式收集失败退出 3；非当前模式收集器不加载、不报错。
6. **性能有界**：先元数据后内容，懒加载 blob，超限跳过或退出 3，并输出统计。

## 2. 三种审查模式总览

| 模式   | 适用场景                                  | 输入参数                                               | 输出                               |
| ------ | ----------------------------------------- | ------------------------------------------------------ | ---------------------------------- |
| DIFF   | 审查提交、分支、PR、指定 base/head 的变更 | `repoRoot`、`baseRef`、`headRef`、`include`、`exclude` | `DiffResult` + 增量 `SourceBundle` |
| MODULE | 审查一个或多个 Maven/Gradle 模块          | `repoRoot`、`modulePaths`、`include`、`exclude`        | `SourceBundle`                     |
| FILES  | 审查指定文件或目录                        | `repoRoot`、`filePaths`、`include`、`exclude`          | `SourceBundle`                     |

模式优先级：CLI > 环境变量 > `.env.local` > YAML > 默认值。

## 3. M04 范围解析设计

### 接口

| 接口                                    | 输入                   | 输出         | 说明                           |
| --------------------------------------- | ---------------------- | ------------ | ------------------------------ |
| `resolve(ReviewRequest) -> ReviewScope` | 合并后的 ReviewRequest | ReviewScope  | 解析模式、路径、refs、过滤规则 |
| `collect(ReviewScope) -> SourceBundle`  | ReviewScope            | SourceBundle | 分派 M05/M06 并汇总源码快照    |

### 模式判定规则

1. `review.mode` 显式存在：必须为 `DIFF`、`MODULE`、`FILES`，否则退出 3。
2. 未显式时按唯一参数推导：
   - `baseRef` 或 `headRef` 非空 -> DIFF。
   - `modulePaths` 非空 -> MODULE。
   - `filePaths` 非空 -> FILES。
3. 多个来源冲突：退出 2。
4. 均无法判定：使用 E3 默认值；若默认缺失或非法，退出 2。
5. 解析后无有效文件：退出 3。

### 参数校验与失败行为

| 校验项                   | DIFF | MODULE | FILES | 失败退出码 |
| ------------------------ | ---- | ------ | ----- | ---------- |
| `repoRoot` 存在且可读    | 必须 | 必须   | 必须  | 3          |
| `baseRef/headRef` 可解析 | 必须 | 忽略   | 忽略  | 3          |
| `modulePaths` 非空且存在 | 忽略 | 必须   | 忽略  | 3          |
| `filePaths` 非空且存在   | 忽略 | 忽略   | 必须  | 3          |
| `include/exclude` 合法   | 必须 | 必须   | 必须  | 2          |
| 至少一个 Java 文件       | 必须 | 必须   | 必须  | 3          |
| 模式枚举合法             | 必须 | 必须   | 必须  | 3          |

### collect 分派

- DIFF：调用 M05 `collectDiff`，生成 `DiffResult`，再按变更新路径构建增量 `SourceBundle`。
- MODULE：调用 M06 `collectModules`。
- FILES：调用 M06 `collectFiles`。
- 统一应用默认排除、用户 include/exclude、语言过滤、空文件/超大文件策略。

## 4. M05 Git Diff 收集设计

### JGit 用法（只读）

- 使用 `RepositoryBuilder.findGitDir(repoRoot).setMustExist(true).build()`。
- 使用 `RevWalk` 解析 ref，`TreeWalk`/`DiffFormatter` 扫描差异。
- 仅读 object database，不写 index、不写工作区、不写 `.git`。
- 不调用 `checkout`、`reset`、`clean`、`stash`、`commit`、`add`。
- Diff 输出到内存流，不落盘到目标仓库。

### baseRef / headRef 语义

- `baseRef`：旧侧基线，默认建议 `HEAD~1`。
- `headRef`：新侧目标，默认建议 `HEAD`。
- 方向：`baseRef -> headRef`，新增/修改行号以 `headRef` 侧为准。
- 支持 SHA、分支、tag、`HEAD`、相对 rev。
- 默认两点 diff；PR 三点 diff 由调用方传入 merge-base 作为 `baseRef`。
设计决策：MVP 不支持工作区未提交变更；如需审查未提交内容，走 FILES 模式。

### 增量文件识别

- 使用 `DiffEntry.ChangeType`：ADDED、MODIFIED、DELETED、RENAMED、COPIED。
- 启用重命名检测，默认相似度阈值 50%。
- 仅收集 Java 文本文件；其他语言记录后跳过。

### 变更行范围识别

- 使用 DiffFormatter 编辑列表，合并相邻/重叠范围为 `LineRange`。
- 行号：1-based，闭区间 `[start, end]`。
- 新增文件：`LineRange(1, totalLines)`。
- 修改文件：仅新侧变更行范围。
- 删除文件：不生成 SourceUnit，记录删除与旧侧范围。

### 重命名与删除文件处理

| 场景         | 处理                                                |
| ------------ | --------------------------------------------------- |
| 重命名       | 记录 `oldPath` 与 `path`，按新路径读取 SourceUnit   |
| 删除         | 记录 ChangedFile，`deleted=true`，不生成 SourceUnit |
| 复制         | 按新增文件处理，记录来源路径                        |
| 重命名且修改 | 新路径 SourceUnit，diffChunks 使用新侧行范围        |

### 二进制文件过滤

- 扩展名过滤：`.class`、`.jar`、`.war`、`.ear`、图片、压缩包、可执行文件等。
- 内容检测：blob 含 NUL 或 JGit 标记二进制则跳过。
- 跳过项计入 `DiffResult.stats.binarySkipped`，不生成 SourceUnit。

### 大 diff 性能考虑

- 先扫描 DiffEntry 元数据，应用 include/exclude。
- 仅对命中的 Java 文本文件读取 blob。
- 单文件、总文件数、总行数、总读取量设软硬上限。
- 超软上限：跳过并记录 `largeSkipped`。
- 超硬上限或超时：退出 3。

### Windows 路径与编码

- 内部路径统一 `/`；Git 路径天然 `/`。
- 映射工作区时使用系统 Path 解析，不假设大小写。
- 源码强制 UTF-8，去除 BOM。
- 行号按 `\n` 计算；`\r\n` 不额外计行。
- 非法 UTF-8：变更 Java 文件退出 3；非 Java 跳过并记录。

## 5. M06 模块/文件收集设计

### 模块识别（Maven / Gradle）

- 不执行 Maven/Gradle 构建，只静态读取描述文件。
- Maven：识别 `pom.xml`，解析 `<modules>`，源根 `src/main/java`，测试根 `src/test/java`。
- Gradle：识别 `settings.gradle(.kts)`、`build.gradle(.kts)`，源根 `src/main/java`。
- 模块名：Maven 用 `groupId:artifactId` 或 `artifactId`；Gradle 用项目路径或相对路径。
- `modulePaths` 可为模块目录、`pom.xml`、`build.gradle(.kts)`。
- 同一文件被多模块包含时，归入最短模块路径。

### 文件路径解析

- `filePaths` 必须存在。
- 文件：直接收集。
- 目录：递归扫描，应用 include/exclude。
- 路径统一相对 `repoRoot` 输出为 `/` 分隔。

### include / exclude 规则

- 默认 include：`**/*.java`。
- 用户 include 非空时先匹配用户 include。
- 默认排除始终生效，不可被 include 覆盖。
- 用户 exclude 追加。
- glob 支持 `*`、`**`、`?`、`{a,b}`。
- Windows 下匹配大小写不敏感；Linux 下大小写敏感。

### 语言过滤

- 只处理 `.java`。
- `SourceUnit.language` 固定为 `java`。
- 非 Java 文件跳过并计入 `nonJavaSkipped`。
- Java 版本目标：Java 17+；不执行编译，仅收集源码。

### 生成代码 / 测试代码识别

| 类型     | 识别规则                                                     | 默认 |
| -------- | ------------------------------------------------------------ | ---- |
| 生成代码 | `generated`、`generated-sources`、`target/generated-*`、`build/generated*`、注解处理器输出 | 排除 |
| 测试代码 | `src/test/java`、`*Test.java`、`*Tests.java`、`*IT.java`     | 包含 |
| 主代码   | `src/main/java` 或其他非排除 Java                            | 包含 |

测试代码默认包含；是否新增 `review.includeTests` 由 E5 决定，本设计不新增 E3 字段。

### Windows 路径与编码

- 路径统一 `/` 输出。
- 大小写仅用于去重，不改变原始大小写。
- UTF-8 读取，去 BOM。
- 非法 UTF-8 Java 文件退出 3；其他文件跳过。
- 不跟随符号链接，除非后续明确配置。

## 6. ReviewScope 结构（对齐 E2）

| 字段           | 类型    | 约束                        |
| -------------- | ------- | --------------------------- |
| `mode`         | enum    | `DIFF` / `MODULE` / `FILES` |
| `repoRoot`     | string  | 绝对路径，规范化            |
| `baseRef`      | string? | DIFF 必填                   |
| `headRef`      | string? | DIFF 必填                   |
| `modulePaths`  | list    | MODULE 非空                 |
| `filePaths`    | list    | FILES 非空                  |
| `changedFiles` | list    | DIFF 时来自 M05             |
| `lineRanges`   | map     | path -> LineRange 列表      |
| `include`      | list    | 用户 include                |
| `exclude`      | list    | 用户 exclude + 默认排除     |

## 7. SourceUnit 结构（对齐 E2）

| 字段         | 类型   | 说明                                |
| ------------ | ------ | ----------------------------------- |
| `path`       | string | 仓库相对路径，`/` 分隔              |
| `language`   | string | 固定 `java`                         |
| `content`    | string | UTF-8 只读快照，去 BOM              |
| `hash`       | string | SHA-256(content UTF-8)              |
| `lines`      | int    | 按 `\n` 计数，1-based               |
| `module`     | string | 模块名或相对路径，未知为 `_root`    |
| `diffChunks` | list   | DIFF 模式变更行范围；其他模式空列表 |

约束：只读源码快照；不写回目标仓库；不包含二进制。

## 8. DiffResult 结构

| 字段                 | 类型   | 说明                   |
| -------------------- | ------ | ---------------------- |
| `repoRoot`           | string | 绝对路径               |
| `baseRef`            | string | 旧侧                   |
| `headRef`            | string | 新侧                   |
| `resolvedBaseCommit` | string | 解析后 SHA             |
| `resolvedHeadCommit` | string | 解析后 SHA             |
| `changedFiles`       | list   | `ChangedFile` 列表     |
| `lineRanges`         | map    | path -> LineRange 列表 |
| `stats`              | object | 统计                   |
| `skipped`            | object | 跳过原因与计数         |
| `warnings`           | list   | 非致命告警             |

`ChangedFile`：`path`、`oldPath`、`changeType`、`language`、`binary`、`deleted`、`lineRanges`、`included`。  
`LineRange`：`start`、`end`、`side`、`changeType`。  
`stats`：`total`、`added`、`modified`、`deleted`、`renamed`、`binarySkipped`、`largeSkipped`、`nonJavaSkipped`、`collected`。

## 9. 文件过滤规则

| 规则           | 决策                                                         |
| -------------- | ------------------------------------------------------------ |
| 默认排除目录   | `target`、`build`、`generated`、`generated-sources`、`vendor`、`node_modules`、`.git` |
| 默认排除二进制 | `.class`、`.jar`、`.war`、`.ear`、`.so`、`.dll`、`.exe`、`.bin` |
| 默认排除图片   | `.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.ico`             |
| 默认排除压缩包 | `.zip`、`.tar`、`.gz`、`.7z`、`.rar`                         |
| 测试代码       | 默认包含；路径与命名识别                                     |
| 空文件         | 0 字节或仅空白跳过，不生成 SourceUnit                        |
| 超大文件       | 单文件 > 1 MiB 默认跳过并记录；硬上限 > 5 MiB 退出 3         |
| 非 Java        | 跳过并记录                                                   |

## 10. 只读保证

- 不使用写操作写目标仓库。
- 不执行 `git checkout`、`git reset`、`git clean`、`git stash`、`git add`、`git commit`。
- 不修改工作区、不修改 index、不写 `.git`。
- 不运行 Maven/Gradle 构建，不触发插件。
- 不训练模型、不修改规则文件。
- 仅向 `output.dir/latestDir/historyPattern` 写报告。

## 11. 异常与降级

| 场景                     | 行为                           | 退出码 |
| ------------------------ | ------------------------------ | ------ |
| Git 未安装               | DIFF 退出 3；MODULE/FILES 忽略 | 3      |
| 非 Git 仓库              | DIFF 退出 3；MODULE/FILES 继续 | 3      |
| `baseRef/headRef` 不存在 | DIFF 退出 3                    | 3      |
| 路径不存在               | MODULE/FILES 退出 3            | 3      |
| 大 diff 超时             | DIFF 退出 3                    | 3      |
| 大 diff 超软上限         | 跳过并记录                     | 0      |
| 非法 UTF-8 Java          | 退出 3                         | 3      |
| 空范围                   | 退出 3                         | 3      |
| 权限不足                 | 退出 3                         | 3      |
| 内部错误                 | 退出 6                         | 6      |

## 12. 性能与规模

| 项             | 默认策略                                               |
| -------------- | ------------------------------------------------------ |
| 大仓库         | 只读树扫描，不 checkout，懒加载 blob                   |
| 并行           | 按 CPU/2 并行读取与 hash，保持顺序输出                 |
| 大 diff 上限   | 变更文件 2000；单文件 1 MiB；总行 200k；总读取 100 MiB |
| 增量文件数上限 | 2000；超硬上限退出 3                                   |
| 超时           | 扫描 30s；总收集 120s；超时退出 3                      |
| 缓存           | 只读内容 hash 可内存缓存；不写磁盘缓存到目标仓库       |
| 配置化         | 上限与超时建议 E5 扩展配置；当前设计为默认值           |

## 13. 模块接口（对齐 E2 M04/M05/M06 契约）

| 模块 | 接口                                            | 输入                                     | 输出             | 依赖         | 降级             |
| ---- | ----------------------------------------------- | ---------------------------------------- | ---------------- | ------------ | ---------------- |
| M04  | `resolve(ReviewRequest) -> ReviewScope`         | ReviewRequest                            | ReviewScope      | M05/M06/M18  | 不可关闭         |
| M04  | `collect(ReviewScope) -> SourceBundle`          | ReviewScope                              | SourceBundle     | M05/M06/M18  | 不可关闭         |
| M05  | `collectDiff(DiffRequest) -> DiffResult`        | repoRoot/baseRef/headRef/include/exclude | DiffResult       | JGit/M18     | 非 DIFF 可关闭   |
| M05  | `changedLines(path) -> LineRange`               | path                                     | LineRange        | JGit/M18     | 非 DIFF 可关闭   |
| M05  | `changedFiles() -> List<ChangedFile>`           | 无                                       | ChangedFile 列表 | JGit/M18     | 非 DIFF 可关闭   |
| M06  | `collectModules(ModuleRequest) -> SourceBundle` | modulePaths/include/exclude              | SourceBundle     | 文件系统/M18 | 非 MODULE 可关闭 |
| M06  | `collectFiles(FileRequest) -> SourceBundle`     | filePaths/include/exclude                | SourceBundle     | 文件系统/M18 | 非 FILES 可关闭  |

## 15. 未决问题

1. 是否默认使用 merge-base 三点 diff。
2. 浅克隆仓库中 baseRef/headRef 缺失时的降级策略。
3. Gradle Kotlin DSL 解析深度；是否只做正则级 include 提取。
4. LineRange.side 是否区分 OLD/NEW，或仅输出新侧。
5. 子模块、符号链接、大小写敏感去重策略。
6. 是否支持工作区未提交变更（未来扩展）。

## 16. 对 E5～E11 的影响

| 阶段          | 影响                                                         |
| ------------- | ------------------------------------------------------------ |
| E5 规则加载   | 消费 SourceUnit 与 diffChunks；规则选择需按 module_type 过滤 |
| E6 规则加载   | 消费 SourceUnit 与 diffChunks；需保持只读                    |
| E7 JavaParser | 基于 SourceUnit.content 解析；行号与 LineRange 对齐          |
| E8 规则执行   | 测试/生成代码通过路径与 module 推断，不新增 SourceUnit 字段  |
| E9 报告       | 使用 DiffResult.stats/skipped/warnings 输出范围摘要          |
| E10 输出      | JSON 对齐 A5/A6，不新增 schema 字段；新增字段需走 schema 变更 |
| E11 可观测    | 统一退出码 3 表示范围/代码收集失败；日志记录跳过原因与上限命中 |
